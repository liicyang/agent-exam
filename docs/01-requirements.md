# 需求与成功标准

用户是内容运营人员，目标是把待处理素材变成无冲突、可确认的排期草稿。

范围：单素材请求、合成元数据、合成审核规则、固定候选时段、本地持久化。非目标：真实发布、媒体内容识别、线上 UI、多 Agent、生产级审核和跨时区排期。

每项结果包含审核状态、风险原因、建议时段、待确认事项、保存状态和任务状态。数据不足不能视为审核通过；规则风险阻断；硬性发布时间只有用户显式确认后才能变更；模型不得制造保存成功或发布成功。

成功标准：正常路径保存一份草稿；缺失信息请求补充；违规阻断；占用时段提出有工具依据的替代建议；重复请求只有一份草稿；存储失败无草稿且明确失败。至少两条真实模型运行路径显示观察工具结果后调整行动。

将业务工具用本地函数实现；SQLite 仅是存储实现，Python 自带接口。3 小时内优先可运行闭环、真实记录和可解释的边界。当前真实模型验收仍待密钥配置。
